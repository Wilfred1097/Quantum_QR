# 🦖 Quantum QR — Modern QR Code Generator

**Quantum QR** is a fast, feature-rich, and elegant web-based QR code generator built with modern web technologies. Moving far beyond basic text generators, it features a stunning glassmorphism UI, real-time live preview, custom styling options, multiple data formats (URLs, Wi-Fi networks, and vCards), and one-click export to PNG, JPEG, or clipboard.

![image_alt](https://github.com/Wilfred1097/qr-generator/blob/main/sample-ui.PNG?raw=true)

🌐 **Live Demo:** [https://wilfred1097.github.io/qr-generator/](https://wilfred1097.github.io/qr-generator/)

---

## ✨ Key Features

- **🎨 Multi-Format Generation:** Create QR codes effortlessly for multiple use cases:
  - **Text / URL:** Standard links, messages, and raw text.
  - **Wi-Fi Networks:** Easily share network credentials (SSID, security type, password) so users can scan to connect instantly.
  - **vCard / Contact Cards:** Generate digital contact business cards containing names, phone numbers, emails, and organizations.
- **⚡ Real-Time Live Preview:** Watch your QR code update instantly as you type or change parameters (with a toggle switch to enable/disable).
- **🎨 Custom Styling & Sizing:** 
  - Choose custom **Foreground** and **Background** colors with live hex code indicators.
  - Scale resolution dynamically from standard sizes up to **1000x1000 HD**.
- **📥 Robust Export Options:** Download your generated QR codes instantly in high-quality **PNG** or **JPEG** formats, or copy them directly to your clipboard with a single click.
- **🔒 100% Privacy-First:** All QR code generation happens entirely client-side right inside your browser—no user data, personal info, or inputs are ever sent to or stored on external servers.
- **📱 Responsive Glassmorphism UI:** Built with Tailwind CSS, featuring a sleek dark-mode glass aesthetic that looks breathtaking on desktops, tablets, and mobile devices.

## 🛠️ Built With

* **HTML5 / JavaScript (ES6+)** — Core structure and dynamic reactive logic.
* **Tailwind CSS** — Modern, utility-first styling and glassmorphism design system.
* **QRious Library** — Lightweight, high-performance canvas-based QR code generation.
* **FontAwesome** — Crisp, scalable vector icons.

## 🚀 Getting Started Locally

To run or develop a local copy of **Quantum QR**:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/wilfred1097/qr-generator.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd qr-generator
   ```

3. **Open the application:**
   Simply double-click and open `index.html` in your favorite web browser, or serve it using a local development server (such as Live Server in VS Code).

---

## 💡 How to Use

1. **Select your content type** using the navigation tabs (Text/URL, Wi-Fi, or vCard).
2. **Fill in the details** required for your QR code.
3. **Customize your design** by choosing your preferred foreground/background colors and resolution size.
4. **Download or Copy** your finalized QR code instantly using the action buttons below the live preview!
